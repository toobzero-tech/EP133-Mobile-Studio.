# PRICE RADAR Android 1.1.0

Нативный Android-интерфейс для сравнения цен по пяти российским магазинам:

- DNS
- М.Видео
- Ozon
- Wildberries
- Яндекс Маркет

## Что работает в версии 1.1.0

- поиск одного товара в выдаче каждого из пяти магазинов;
- отдельная карточка магазина с кнопкой открытия поиска;
- ручная фиксация фактической цены и ссылки на конкретный товар;
- сравнение минимальной, максимальной и средней введённых цен;
- расчёт разницы в рублях и процентах;
- сохранение цен и ссылок для каждого поискового запроса;
- история последних восьми запросов;
- сохранение города (по умолчанию Санкт-Петербург);
- интерфейс и логика выполнены на Android Views, без WebView.

## Что добавлено в 1.2.0

- приём ссылок из меню «Поделиться» Android для DNS, М.Видео, Ozon, Wildberries и Яндекс Маркета;
- автоматическое определение магазина по домену и сохранение ссылки в соответствующую карточку;
- официальный адаптер Реферальной программы Яндекс Маркета: по переданной ссылке на конкретный товар запрашивает цену и остаток через `GET /v3/affiliate/partner/link/create`;
- отображение источника и времени последней проверки цены;
- OAuth-токен хранится в зашифрованном виде с ключом Android Keystore;
- добавлено сетевое разрешение Android.

Для автоматического получения цены Яндекс Маркета нужны действующий договор/доступ к Реферальной программе, OAuth-токен и `place_id` площадки из раздела «Блоги». Приложение не выполняет поиск каталога Яндекс Маркета через API: пользователь сначала открывает карточку товара и делится её ссылкой с PRICE RADAR.

## Чего пока нет

Автоматический поиск и сбор цен по произвольному текстовому запросу из DNS, М.Видео, Ozon и Wildberries не подключены. Для этих магазинов ссылка добавляется через системное меню «Поделиться», а цена пока вводится после проверки карточки. API Яндекс Маркета в этой версии разрешает получить цену по конкретной переданной ссылке, но не предоставляет в используемом разделе API поиск по общему запросу.

## Сборка

Проект собирается GitHub Actions workflow .github/workflows/build-price-radar-android.yml.

- Application ID: com.toobzero.priceradar
- Minimum Android: 9 / API 28
- Target SDK: 35
- Java: 17
- Android Gradle Plugin: 8.7.3
- Kotlin plugin: 2.0.21

Следующий этап автоматизации: получить официальные API/партнёрские фиды для каждой площадки, затем подключать их по одному с проверкой актуальности цены, региона, наличия и прямой ссылки на карточку.
