Данные сохраняются локально в этом браузере. Автосбор выполняется отдельным заданием GitHub Actions для разрешённых источников. Его JSON-выгрузку можно загрузить кнопкой «Импорт объявлений JSON». Новые объявления добавляются без выдуманной рыночной оценки: укажите цену перепродажи вручную или дождитесь отдельной оценки по завершённым продажам. Импорт CSV поддерживает кавычки и запятые внутри полей.

Импорт CSV

Колонки: name,buy,market,fees,source. Можно выбрать файл или вставить текст. Десятичная запятая поддерживается, если число не заключено в кавычки с разделителем.
