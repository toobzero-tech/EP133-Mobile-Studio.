# KOII Studio Desktop 0.8.1

Это настольная оболочка Windows для исходного интерактивного демо KOII Studio 0.7.0.

Сейчас реализованы в исходном интерфейсе: Web Audio-пэды, синтезированные ударные и Acid-тон, 16-шаговые паттерны, импорт сэмплов, запись микрофона (при поддержке браузерного движка), сохранение/загрузка JSON-проекта. Часть кнопок и аппаратных функций ещё требует реализации.

Сборка portable EXE выполняется GitHub Actions на Windows. Результат появится в Artifacts после успешного workflow.

Это не заявляется как полная прошивочная/аппаратная копия EP-133. Следующие этапы: точная панель, группы A-D и сцены, полноценный sample editor, эффекты и экспорт аудио.
