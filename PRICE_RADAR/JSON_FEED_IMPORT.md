# JSON feed import

Импортёр подключает публичные JSON API/фиды, которые владелец источника разрешил читать и использовать. Это не универсальный парсер сайтов.

## Запуск

```bash
python PRICE_RADAR/tools/import_json_feeds.py PRICE_RADAR/json-feeds.example.json -o json_offers.json
```

1. Получите у российского магазина/партнёра публичный HTTPS endpoint и разрешение на периодическое чтение данных.
2. Настройте `items_path` и `fields` по документации конкретного API.
3. Установите `country_confirmed: true` только после подтверждения, что выдача относится к РФ.
4. Установите `currency_confirmed: true` и `currency_constant: "RUB"` только если владелец API прямо гарантирует рубли для всех записей. Предпочтительнее передавать валюту в каждой записи через поле `currency`.
5. Включите источник и запустите импорт.

Поддерживаются вложенные пути через точку, например `data.items` или `price.amount`. Если поле отсутствует, оно не выдумывается. Валюта не считается RUB по умолчанию. Записи без названия, HTTPS-ссылки, положительной цены или подтверждённой рублёвой валюты не попадут в итоговый файл.

Защита: только HTTPS, редирект только на исходный hostname, таймаут 15 секунд, максимум 2 МБ на ответ. Ограничения частоты задаются паузой между фидами; соблюдайте лимиты конкретного API. Авторизацию, CAPTCHA, paywall и антибот-защиту не обходить.

Пример конфигурации отключён. Реальный endpoint должен быть предоставлен и разрешён его владельцем.
