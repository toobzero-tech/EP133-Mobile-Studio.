Аукционы скрыты по умолчанию. Показываем только лоты, заканчивающиеся в течение 24 часов, с дисконтом от 20%, положительной расчётной прибылью и рейтингом сделки от 60/100. Без времени окончания аукцион не попадает в ленту.

Работа ведётся только по России. Российские магазины и площадки можно указать вручную; автоматическое подключение каждого источника требует отдельного разрешённого API или партнёрского фида. Данные хранятся локально в браузере на этом устройстве. Прибыль = рыночная оценка − цена объявления − дополнительные расходы − комиссия при продаже − налоговый резерв − резерв на риск. ROI = чистая прибыль / (цена покупки + дополнительные расходы). Предельная цена покупки — максимум, при котором расчётная прибыль не ниже нуля. Рыночную оценку товаров нужно подтверждать завершёнными продажами сопоставимых товаров; для недвижимости сравнение идёт по типу объекта, городу, площади (±20%) и комнатности, а цена за м² умножается на площадь объекта. Автоматический сбор объявлений пока не подключён: он будет возможен только через разрешённые API, RSS, открытые выгрузки или партнёрские фиды. Демопримеры условные. *Прибыль предварительная; налоговый резерв задаётся отдельно.
