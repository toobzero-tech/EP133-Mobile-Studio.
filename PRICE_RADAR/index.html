Работа ведётся только по России. Российские магазины и площадки можно указать вручную; автоматическое подключение каждого источника требует отдельного разрешённого API или партнёрского фида. Данные хранятся локально в браузере на этом устройстве. Прибыль = рыночная оценка − цена объявления − дополнительные расходы − комиссия при продаже − налоговый резерв − резерв на риск. Рыночную оценку нужно подтверждать завершёнными продажами сопоставимых товаров. Автоматический сбор объявлений пока не подключён: он будет возможен только через разрешённые API, RSS, открытые выгрузки или партнёрские фиды.
