# Развёртывание PRICE RADAR

## Что уже подготовлено
Сервис FastAPI отдаёт веб-интерфейс и API на одном домене:
- `/` — веб-приложение;
- `/health` — проверка сервиса и наличия APISH_API_KEY (значение ключа не раскрывается);
- `/api/search?q=...` — поиск объявлений Avito через API.SH.

## Render
1. Откройте Render и выберите **New → Blueprint**.
2. Подключите репозиторий `toobzero-tech/EP133-Mobile-Studio.`.
3. В качестве ветки выберите `price-radar-mvp`, где лежит актуальная версия проекта.
4. Render прочитает корневой `render.yaml` и создаст web service `price-radar-api`.
5. В настройках созданного сервиса добавьте `APISH_API_KEY` со своим ключом API.SH.
6. Добавьте `GEMINI_API_KEY` из Google AI Studio, чтобы включить кнопку «Анализ ИИ». Ключ хранится только в Render Environment.
7. Сохраните переменные и дождитесь успешного Deploy.
8. Откройте адрес Render:
   - `/health` должен вернуть `status: ok`, `apish_configured: true` и `gemini_configured: true`;
   - после этого выполните один поиск с коротким запросом, например `/api/search?q=фотоаппарат&location=rossiya`;
   - затем можно проверить анализ одного объявления кнопкой «Анализ ИИ».

## Расход кредитов
- API.SH Search тарифицируется по 5 кредитов за выполненный запрос.
- По умолчанию сервер ограничивает поиск 30 запросами в UTC-сутки и не принимает запросы чаще одного раза в 2 секунды на один процесс.
- Эти ограничения задаются переменными `APISH_DAILY_CALL_LIMIT` и `APISH_MIN_INTERVAL_SECONDS`.
- Не запускайте повторные тесты, если не уверены в остатке кредитов.

## Важно
- Не публикуйте APISH_API_KEY или GEMINI_API_KEY в чате, исходниках или GitHub Issues.
- API.SH списывает кредиты за поиск; не запускайте повторные тесты без необходимости.
- Gemini может тарифицироваться по использованным токенам и изображениям согласно тарифу Google AI Studio. В приложении установлен предел 10 анализов в сутки на один процесс; перед включением проверьте актуальные цены и квоты своего проекта.
- Если ключ Gemini отсутствует, поиск Avito остаётся доступен, а кнопка анализа вернёт понятное сообщение о настройке.
- Пока нет ключа и успешного живого запроса, реальный поиск Avito не считается включённым.
