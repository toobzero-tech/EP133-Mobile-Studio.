# PRICE RADAR: карта российских источников

Проверено: 23.11.2026. Статусы ниже относятся к публично описанным возможностям, а не к фактически подключённым аккаунтам.

## Источники объявлений

### Авито
- Официальный портал: https://developers.avito.ru/
- Официальные API в основном обслуживают данные авторизованного аккаунта: собственные объявления, сообщения, статистику и связанные операции.
- Публичный универсальный API для поиска всех чужих объявлений не подтверждён.
- Статус PRICE RADAR: ручные ссылки и импорт разрешённых выгрузок; автоматический поиск чужих объявлений не подключён.

### Мешок
- Документация: https://meshok.net/help_api.php
- Документация описывает авторизацию токеном и ограничение частоты запросов.
- Методы списка лотов относятся к лотам пользователя/его аккаунта; универсальный поиск чужих лотов не подтверждён.
- Статус PRICE RADAR: потенциальная интеграция для собственных лотов после проверки токена и методов. Не считать источником рыночного поиска.

### Юла
- Справка: https://help.youla.ru/
- Бесплатный официальный публичный API для массового поиска чужих объявлений не подтверждён.
- Статус PRICE RADAR: ручные ссылки и разрешённые выгрузки.

## Публичный специализированный API

### Golova.Market
- Документация: https://golovamarket.ru/developers и публичная OpenAPI 3.1: https://golovamarket.ru/api/public/openapi.json.
- Документация заявляет публичный read-only REST API без ключа и регистрации, лимит 60 запросов в минуту. Есть поиск объявлений по запросу, категориям, брендам, городу, цене, состоянию и сортировке.
- Ограничение: площадка специализируется на профессиональном оборудовании для сцены, медиа и кино, а не на всех товарных категориях.
- Статус PRICE RADAR: живой API проверен в GitHub Actions. Фактический ответ содержит пагинацию, id/slug/title/brand/model/price/currency/city/type/condition/category/seller/images. Импортёр реализован: только type=sale, точное совпадение с белым списком городов РФ, явная RUB, положительная цена и slug; аренда и цена по запросу исключаются. Дата публикации в кратком ответе отсутствует и не выдумывается. Полный многогородской сбор запускается отдельным workflow вручную.

## Российские розничные сети и маркетплейсы

В приоритетном списке: DNS, Ситилинк, М.Видео, Эльдорадо, Ozon, Wildberries, Яндекс Маркет, Мегамаркет и специализированные российские магазины.

- Яндекс Маркет: API продавца работает с данными кабинета продавца; API поиска по каталогу Яндекса имеет отдельные требования и не является универсальным фидом чужих предложений. Документация: https://yandex.ru/dev/market/partner-api/doc/ru/ и https://yandex.ru/dev/site/api/ru/concepts/catalogue
- DNS, Ситилинк, М.Видео, Эльдорадо, Ozon, Wildberries и Мегамаркет: автоматический публичный API или фид для независимого массового поиска ценовых аномалий в рамках этого проекта пока не подтверждён.
- Партнёрский YML/XML/CSV фид может быть подключён, если его владелец прямо разрешил использование и предоставил ссылку или файл.

### Яндекс Маркет: партнёрский API
- Помимо API продавца существует отдельный API партнёрской сети Маркета. Для доступа требуются договор с партнёрской сетью и API-ключ; использование ограничено условиями договора и показом предоставляемых данных на сайте/в приложении партнёра.
- Это потенциальный источник товарных карточек и ценовых ориентиров, но не открытый анонимный API и не готовая глобальная база объявлений для перепродажи.
- Документы: https://yandex.ru/legal/market_affiliate_api/ru и https://yandex.ru/dev/market/partner-api/doc/ru/.

### Ozon: Statistics API
- Ozon отдельно описывает Statistics API для аналитических сервисов: данные по товарам, характеристикам, ценам, остаткам, рейтингам и отзывам.
- Доступ не выдаётся обычным продавцам через Seller API; независимому аналитическому сервису предлагается обращаться за коммерческим доступом на request-data@ozon.ru.
- Это один из наиболее перспективных кандидатов для ценового мониторинга, но интеграцию нельзя считать доступной до получения официального доступа, согласования условий и проверки фактической схемы API.
- Документ Ozon: https://dev.ozon.ru/news/256-Novyi-API-dlia-polucheniia-dannykh-Statistics-API/.


### Доступ к аналитическим API маркетплейсов
- Ozon Statistics API предназначен для внешней аналитики ассортимента, цен, остатков, рейтингов и отзывов. Официальная публикация Ozon указывает, что API платный, доступ запрашивается по адресу request-data@ozon.ru, решение по заявке может занимать до пяти рабочих дней: https://dev.ozon.ru/start/258-Ozon-zapustil-Statistics-API-dlia-polucheniia-dannykh-o-prodazhakh-na-marketpleise.
- API партнёрской сети Яндекс Маркета требует отдельного договора и API-ключа; данные можно использовать только в рамках открытого сайта или приложения партнёра и с соблюдением лимитов: https://yandex.ru/legal/market_affiliate_api/ru/.
- Обычный API Яндекс Маркета для продавцов предназначен для управления предложениями и заказами конкретного кабинета, а не для общего поиска всех предложений: https://yandex.ru/dev/market/partner-api/doc/ru/.
- Статус PRICE RADAR: эти подключения пока не активны. Нельзя считать наличие документации подтверждением выданного доступа или работающей интеграции.

## Поддерживаемые форматы импорта

- CSV/JSON: ручные и партнёрские выгрузки.
- RSS 2.0 / Atom: публичные фиды, явно разрешённые владельцем.
- YML (Yandex Market Language): товарные предложения партнёра; предложения с `available="false"` пропускаются.
- Для каждого источника должны быть известны разрешённый тип данных, условия хранения и коммерческого использования, лимиты и формат цены.
- В ленту попадают только записи с положительной ценой в RUB, названием и HTTPS-ссылкой.

## Правила доступа и география

- Только Российская Федерация; цены в RUB, регион и доставка по России.
- Не подключать зарубежные магазины, международные маркетплейсы, импорт и валютную конвертацию.
- Не обходить CAPTCHA, авторизацию, paywall, блокировки, лимиты и условия площадок.
- Отсутствие записи в очередной выгрузке не означает, что товар продан.
- Если нет официального API или разрешённого партнёрского фида, использовать ручной импорт, а не скрытый парсер.
