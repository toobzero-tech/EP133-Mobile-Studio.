# PRICE RADAR: карта источников данных
Проверено: 23.11.2026. Это техническая оценка доступности, не обещание интеграции.

## 1. Мешок
- У площадки опубликована документация API: https://meshok.net/help_api.php
- Документация описывает авторизацию токеном из профиля и ограничение до одного обращения в секунду с одного IP.
- В числе методов есть getItemList и getFinishedItemList. По описанию это списки лотов пользователя/его аккаунта, а не универсальный поиск по всей площадке.
- Вывод: API может быть полезен для контроля собственных лотов и их завершения, но пока не подтверждён как источник чужих объявлений для арбитражного поиска.
- Нужна проверка полного списка методов и прав токена перед реализацией.

## 2. Авито
- Официальный портал разработчиков: https://developers.avito.ru/
- Публичная документация и обзоры API указывают, что стандартные методы API ориентированы прежде всего на управление объявлениями и данными аккаунта владельца.
- Нельзя считать официальный API способом поиска всех чужих объявлений. Доступность зависит от типа аккаунта/тарифа и разрешений.
- Не подключать сторонний парсер автоматически: сначала проверять договор, цену, законность доступа, лимиты, хранение данных и право на коммерческое использование.

## 3. Юла
- Публичная справка: https://help.youla.ru/
- В ходе проверки не найден подтверждённый бесплатный официальный публичный API для массового поиска чужих объявлений.
- На рынке есть сторонние API-посредники, но они могут быть платными и требуют отдельной проверки условий и происхождения данных.
- Статус: ручной импорт/ссылка до подтверждения официального разрешённого канала.

## 4. Правило подключения
Для каждого источника перед запуском должны быть известны:
1. Официальный URL документации и владелец API.
2. Разрешённый тип данных: чужие публичные объявления или только собственный кабинет.
3. Цена и лимиты запросов.
4. Условия хранения, обновления и коммерческого использования.
5. Поля времени публикации, идентификатора, URL, цены и состояния.

Нельзя обходить CAPTCHA, авторизацию, paywall, блокировки или лимиты. Если источник не даёт разрешённого доступа, используем ручную ссылку, экспорт пользователя или партнёрскую выгрузку.

## 5. Текущая стратегия
- Мешок: исследовать API для собственных лотов, не выдавать его за общий поисковый API.
- Авито: запросить/проверить официальный доступ к нужным методам; не рассчитывать на массовый поиск чужих объявлений через API аккаунта.
- Юла: оставить ручной импорт до появления подтверждённого канала.
- Общий слой PRICE RADAR: принимать единый CSV/JSON формат от разрешённых источников и выполнять нормализацию, дедупликацию, оценку прибыли и сортировку.

## 4. Яндекс Маркет
- Официальная документация API продавца: https://yandex.ru/dev/market/partner-api/doc/ru/
- API бесплатен, но предназначен для управления магазином продавца: ассортиментом, ценами, остатками, заказами и отчётами. Он не является общедоступным API для поиска всех чужих предложений на витрине.
- Метод получения товаров каталога возвращает товары кабинета продавца, а не весь каталог Маркета.
- Отдельный API поиска по товарам Яндекса требует собственного сайта, подтверждения прав в Вебмастере, YML-фида и OAuth. Это не универсальный поисковый API по всей витрине Маркета.
- Вывод: включаем Яндекс Маркет в список площадок для ручного добавления ссылок и как ориентир розничной цены. Автоматический сбор чужих предложений через API пока не заявляем. Для API продавца нужен собственный кабинет и токен.

## 8. География проекта: только Россия
Решение проекта: PRICE RADAR ищет и оценивает предложения только на территории Российской Федерации.
- Не подключать зарубежные магазины и международные маркетплейсы как источники поиска.
- Не учитывать импорт, таможню и конвертацию иностранных валют в основном поиске.
- Российские магазины и площадки включать только после проверки официального API, разрешённого фида или другого легального способа получения данных.
- Принимать цены в RUB; регион продавца и стоимость доставки по России учитывать отдельно.
- Удалить из приоритетного плана международные интеграции eBay, Amazon, Walmart и Kaufland. Ранее описанные международные API не являются задачей проекта.
- Яндекс Маркет, Авито, Мешок, Юла и российские розничные сети остаются в области проекта, но автоматический доступ проверяется отдельно для каждого источника.
