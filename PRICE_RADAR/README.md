# PRICE RADAR MVP 0.2

## Запуск
1. Скачайте ZIP-артефакт из GitHub Actions.
2. Распакуйте архив.
3. Откройте `index.html` в современном браузере.
4. Добавляйте предложения вручную или нажмите «Добавить примеры».

## Возможности
- единая лента объявлений;
- фильтр по состоянию: новый / Б/У;
- поиск по названию, категории и площадке;
- сортировка по свежести, ожидаемой прибыли, дисконту и рейтингу;
- расчёт прибыли с учётом дополнительных расходов, комиссии и резерва на риск;
- отдельные показатели актуальности и перспективности сделки;
- ручная оценка уверенности рыночной цены и риска сделки;
- локальное хранение в браузере;
- импорт и экспорт CSV.

## Ограничения
Это локальный MVP. Автоматический сбор объявлений с Авито, Мешка, Юлы и других площадок не подключён. Источники можно добавлять только после проверки разрешённых API, RSS, публичных выгрузок или партнёрских фидов и правил площадок.

Рыночная оценка вводится вручную и должна подтверждаться сопоставимыми завершёнными продажами. Рейтинг предварительный и не гарантирует, что товар удастся купить или перепродать с прибылью. Дополнительные расходы нужно указывать самостоятельно.
