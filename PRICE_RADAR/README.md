# PRICE RADAR MVP 0.6

## Запуск
1. Скачайте ZIP-артефакт из GitHub Actions.
2. Распакуйте архив.
3. Откройте `index.html` в современном браузере.
4. Добавляйте предложения вручную или нажмите «Добавить примеры».

## Возможности
- единая лента объявлений;
- фильтр по состоянию: новый / Б/У;
- исключение аукционов по умолчанию; показ только аукционов с окончанием в ближайшие 24 часа, дисконтом от 20%, положительной расчётной прибылью и рейтингом сделки от 60/100;
- отдельное поле даты окончания аукциона;
- поиск по названию, категории и площадке;
- сортировка по свежести, ожидаемой прибыли, ROI, дисконту и рейтингу;
- расчёт прибыли с отдельными комиссиями при продаже, налоговым резервом, расходами и резервом на риск;
- поддержка новых, Б/У, витринных и восстановленных товаров;
- нормализация российских источников и отсечение записей в валюте, отличной от RUB;
- отдельные показатели актуальности и перспективности сделки;
- рейтинг сделки учитывает дисконт (30%), уверенность оценки (25%), риск (15%), ROI (20%) и чистую маржу (10%);
- ручная оценка уверенности рыночной цены и риска сделки;
- поля бренда и точной модели для сопоставления товаров;
- импорт JSON с подтверждёнными завершёнными продажами и автоматическая переоценка по точным совпадениям бренд + модель + состояние;
- приоритет медианы завершённых продаж над ручной оценкой; если совпадений нет, используется ручная оценка, а если и её нет, рынок не оценивается;
- оценка уверенности снижается при малом числе аналогов, старых продажах и большом разбросе цен;
- обязательная явная проверка страны RU и валюты RUB; валюта не предполагается, если поле отсутствует;
- локальное хранение в браузере;
- импорт и экспорт CSV;
- импорт нормализованных объявлений из JSON, включая выгрузку Golova.Market.

## Импорт завершённых продаж
В интерфейсе нажмите «Импорт продаж JSON» и выберите файл с массивом `completed_sales`. Пустой шаблон находится в `completed_sales.template.json`. Запись должна содержать `brand`, `model`, `condition`, а также `status` (`sold`, `completed` или `finished`), `sold_price`, `sold_at`, `country: "RU"` и `currency: "RUB"`. `url` необязательно, но желательно для проверки. Учитываются только продажи за последние 365 дней. Активные объявления, неизвестные даты, другая страна или валюта исключаются. История хранится локально в браузере.

Если есть точные аналоги, приложение рассчитывает медиану и использует её вместо ручной рыночной оценки. В противном случае ручная оценка остаётся резервным вариантом. Не заполняйте историю выдуманными или непроверенными продажами.

## Ограничения
Это локальный MVP. Автоматический сбор чужих объявлений с Авито, Мешка, Юлы и Яндекс Маркета не подключён. Golova.Market подключён отдельным импортёром; для запуска многогородского сбора используйте workflow `PRICE RADAR live Golova scan` в GitHub Actions и импортируйте полученный JSON через кнопку «Импорт объявлений JSON». Добавлены импортёры RSS/Atom/YML и JSON API. Workflow ежедневно объединяет Golova.Market с подключёнными партнёрскими фидами в общий JSON; шаблон подключений находится в `partner-feeds.example.json`. Сейчас шаблон пуст по фактическим источникам: реальные ссылки должны быть предоставлены и разрешены владельцем. Источники можно добавлять только после проверки разрешённых API, RSS, публичных выгрузок или партнёрских фидов и правил площадок.

Рыночная оценка может рассчитываться по импортированной истории сопоставимых завершённых продаж. Если истории продаж нет, приложение может показать осторожный ориентир по двум и более активным объявлениям с точным совпадением бренда, модели и состояния; такой ориентир помечается как активные объявления и имеет низкую уверенность. Рейтинг предварительный и не гарантирует, что товар удастся купить или перепродать с прибылью. Дополнительные расходы нужно указывать самостоятельно.

## Яндекс Маркет
Яндекс Маркет добавлен как площадка для ручного добавления ссылок и как ценовой ориентир при оценке товара. Официальный API продавца работает с каталогом, ценами, остатками и заказами конкретного кабинета; он не предоставляет общий поиск всех чужих предложений. Автоматическое получение данных с витрины не подключено.

## Российский Retail Radar
Планируется отдельный слой поиска уценённых товаров в российских розничных сетях и маркетплейсах: распродажи остатков, open-box, возвраты, refurbished и резкие ценовые провалы. В приоритете российские сети и маркетплейсы: DNS, Ситилинк, М.Видео, Эльдорадо, Ozon, Wildberries и другие. Подключение каждого источника требует проверки российского API или партнёрского фида.

Расчёт ведётся в рублях, учитывает регион продавца, доставку по России и комиссии. Для Golova.Market автоматический импорт продаж реализован. Для полного сбора по российским городам откройте GitHub Actions → `PRICE RADAR live Golova scan` → Run workflow. Полученный артефакт `PRICE_RADAR_Golova_Live_Offers` содержит JSON. В приложении нажмите «Импорт объявлений JSON» и выберите этот файл. При каждой новой сборке ZIP также содержит свежую московскую выборку `golova_market_live_sample.json` (если публичный API доступен). Остальные крупные площадки пока не подключены к автоматическому сбору. Список источников и их ограничения находятся в `SOURCES.md`.


## География
PRICE RADAR работает только по России. Зарубежные магазины, международный поиск, валютная конвертация и импортные пошлины исключены из области проекта.

## Ежедневный сбор по России

В репозитории добавлен workflow **PRICE RADAR daily Russia scan** на ветке по умолчанию: он запускается ежедневно в 03:17 UTC и может быть запущен вручную. Workflow читает список городов из `golova-cities.example.json`, опрашивает публичный read-only API Golova.Market с паузой не менее 1,1 секунды и сохраняет только подтверждённые продажи в RUB по городам РФ. Артефакт `PRICE_RADAR_Golova_Russia_Live` хранится 14 дней; JSON импортируется через кнопку «Импорт объявлений JSON».

Ежедневный workflow дополнительно запускает импорт настроенных RSS/Atom/YML и JSON-фидов и объединяет их с Golova.Market в `PRICE_RADAR_Russia_All_Feeds.json`. Сейчас в шаблоне партнёрских фидов нет реальных включённых источников, поэтому фактическое расширение охвата начнётся после добавления разрешённых ссылок. Это не полный охват Авито, Юлы, Мешка и маркетплейсов.


## Рейтинг сделки 0.4

Рейтинг перспективности больше не строится только на дисконте, уверенности и риске. В него включены ROI и чистая маржа: дисконт — 30%, уверенность рыночной оценки — 25%, обратный риск — 15%, ROI — 20%, маржа от рыночной цены — 10%. ROI-компонент достигает максимума при ROI 50% и выше; маржа — при чистой прибыли от 20% рыночной цены. Это помогает не ставить в топ товары с большим скидочным процентом, но слабой доходностью. Итоговый рейтинг остаётся предварительным и зависит от качества рыночной оценки.





## Статус подключений

В приложении добавлена панель «Источники данных по России». Она показывает не рекламные обещания, а фактический статус: готовность импортёра Golova.Market, ожидание реальных партнёрских фидов, договора и ключа для API партнёрской сети Яндекс Маркета и платного доступа для Ozon Statistics API. Остальные площадки остаются неподключёнными до появления разрешённого источника данных.


## Область поиска

PRICE RADAR предназначен только для поиска физических товаров и оборудования для перепродажи в России. Категории недвижимости в приложении нет.


## Новое в MVP 0.7: сбор разрешённых партнёрских фидов

Добавлен `partner_feed_scan.py` — отдельный сборщик публичных партнёрских источников:
- RSS 2.0 и Atom;
- YML с проверкой `available=true` и `currencyId=RUB`;
- JSON API с настраиваемым `items_path` и сопоставлением полей;
- только HTTPS, товары из РФ и цены в RUB;
- ограничение ответа 12 MiB и таймаут 20 секунд;
- удаление дублей по URL;
- отчёт по каждому источнику: успешно, пропущен или ошибка;
- нормализованный JSON совместим с импортом объявлений в интерфейсе.

Добавлен `.github/workflows/price-radar-partner-feeds.yml`: ручной запуск и ежедневный запуск в 03:43 UTC. Артефакт называется `PRICE_RADAR_Russia_Partner_Feeds` и хранится 14 дней.

Конфигурация находится в `partner-feeds.json`. По умолчанию она намеренно пустая: сборщик не выдумывает источники и не обращается к площадкам без разрешения владельца. Для подключения нужны публичные HTTPS URL, подтверждение географии РФ и валюты RUB. Пример схемы — `partner-feeds.example.json`.

Важно: создание сборщика и workflow не означает, что к нему уже подключены DNS, Ситилинк, М.Видео, Ozon, Wildberries, Авито или Яндекс Маркет. Эти площадки не имеют подтверждённого здесь универсального открытого фида для массового поиска чужих предложений. Их нельзя помечать как подключённые до получения разрешённого доступа.
