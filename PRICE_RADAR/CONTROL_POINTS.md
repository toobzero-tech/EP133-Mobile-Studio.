## КТ-02 — проверка контракта API.SH
Дата проверки: 2026-11-28

### Подтверждено официальной документацией API.SH
- Avito Search endpoint: `GET https://api.api.sh/avito/v1/search`.
- Авторизация: HTTP-заголовок `x-api-key`.
- Минимально нужен один из параметров `q`, `category` или `url`.
- Поиск возвращает до 50 объявлений на страницу и `next_page` для пагинации.
- В результатах документированы: ID, ссылка, заголовок, цена в RUB, описание, параметры, категория, регион, дата публикации, фото, сведения о продавце и `credits_used`.
- Стоимость одного успешного поиска: 5 кредитов.
- Документация: https://api.sh/docs/avito-search
- Обзор Avito API: https://api.sh/avito-api

### Что пока не подтверждено
- Наличие секрета API.SH в GitHub Actions / Render.
- Работоспособность конкретного ключа.
- Реальный ответ API из нашего проекта.
- Наличие интеграции Gemini и рабочего Render deployment.

### Вывод
API.SH документированно предоставляет именно публичный поиск Avito и подходит как источник данных. Запрос не выполнялся: доступ к значению ключа и безопасному тестированию через окружение приложения не подтверждён. Не расходовать кредиты и не записывать ключ в репозиторий.

### Следующая точка — КТ-03

Записать HTTP-статус, число объявлений и наличие обязательных полей. После этого отдельно подключать Gemini.
