# PRICE RADAR — контрольные точки

## КТ-01 — аудит фактического состояния
Дата проверки: 2026-11-28

### Зафиксированная цель
- Единственный источник объявлений для целевого продукта: Avito.
- Искать недооценённые физические товары для перепродажи.
- Анализировать фото, название, описание, состояние, комплектность, модель/материал и рыночные аналоги.
- Показывать реальные объявления с оригинальными ссылками; не подменять данные примерами.
- Gemini — аналитический слой, не источник объявлений.
- API.SH — кандидат на поставщика данных Avito; подключение считается готовым только после проверки ключа и реального ответа API.

### Что подтверждено в репозитории на момент проверки
- Ветка проекта: `price-radar-mvp`.
- Документация `PRICE_RADAR/README.md` описывает локальный MVP 0.7 и прямо указывает, что автоматический сбор Avito не подключён.
- `PRICE_RADAR/index.html` содержит ручное добавление, импорт JSON и список нескольких площадок; это не соответствует финальной концепции Avito-only.
- `PRICE_RADAR/partner-feeds.json` содержит пустые массивы RSS/Atom/YML/JSON.
- Импортёр Golova.Market существует отдельно и не является Avito.
- В просмотренном workflow `.github/workflows/price-radar-daily-scan.yml` нет шага Avito/API.SH и нет использования секрета `APISH_API_KEY`.
- В просмотренных файлах не обнаружено подтверждения подключения Gemini или Render. Это не доказывает отсутствия настроек в секретах/внешнем кабинете, только отсутствие подтверждения в проверенных файлах.

### Следующий этап — КТ-02
1. Проверить наличие настроек/секрета API.SH без раскрытия значения секрета.
2. Установить точную документацию и контракт API.SH для Avito: endpoint, параметры, лимиты, формат ответа.
3. Выполнить один минимальный безопасный запрос и сохранить только факт статуса, количество результатов и структуру полей, не секрет.
4. Если API.SH не поддерживает нужный поиск или ключ отсутствует, остановиться и зафиксировать блокер, не имитировать Avito-данные.
5. Только после успешного теста подключать Gemini и проверять один реальный лот сквозным сценарием.
