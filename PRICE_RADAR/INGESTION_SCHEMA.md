# PRICE RADAR: формат входящих объявлений (v1)

Любой разрешённый источник должен преобразовать объявление в эту общую структуру.

| Поле | Тип | Обязательное | Назначение |
|---|---|---:|---|
| source | string | да | avito / meshok / youla / yandex_market / manual / partner |
| source_id | string | нет | ID лота на площадке |
| url | string | да | Каноническая ссылка |
| title | string | да | Название |
| description | string | нет | Описание |
| category | string | нет | Категория |
| brand | string | нет | Бренд для точного сопоставления товаров |
| model | string | нет | Модель / артикул для точного сопоставления |
| condition | string | да | new / used / refurbished / open_box / unknown |
| price | number | да | Цена в RUB |
| currency | string | да | Только RUB; предложения в другой валюте не попадают в российскую ленту |
| country | string | да | RU; проект ограничен Российской Федерацией |
| location | string | нет | Регион/город в России |
| published_at | ISO-8601 | нет | Время публикации, если источник его даёт |
| observed_at | ISO-8601 | да | Когда PRICE RADAR увидел лот; используется для рейтинга свежести в приложении |
| seller_id | string | нет | Псевдо-ID продавца, если разрешён |
| image_urls | array | нет | Публичные URL изображений, если разрешено |
| completeness | string | нет | Комплектность/дефекты |
| raw | object | нет | Исходные поля для аудита |
| listing_type | string | нет | fixed / auction; по умолчанию fixed |
| ends_at | ISO-8601 | для аукциона | Время завершения аукциона |

## Российские источники
Нормализатор приводит названия площадок к кодам: avito, meshok, youla, yandex_market, ozon, wildberries, dns, citilink, mvideo, eldorado, megamarket. Неизвестные источники сохраняют нормализованное имя. Валюта отличная от RUB помечается UNSUPPORTED и не должна включаться в выдачу.

## Дедупликация
1. Сначала source + source_id.
2. Если ID нет: нормализованный URL.
3. Резервный отпечаток: нормализованный заголовок + цена + регион + источник.
4. Не объединять похожие объявления разных продавцов автоматически: это могут быть разные товары.

## Статусы актуальности
- new: обнаружено недавно.
- active_confirmed: повторно подтверждено источником.
- stale_unchecked: давно не проверялось.
- unavailable: источник подтвердил, что лот снят/продан.
- manual_unverified: пользователь добавил ссылку, но наличие не проверено.

Отсутствие объявления в очередной выгрузке само по себе не доказывает, что оно продано. В таком случае ставить stale_unchecked, а не unavailable.

## Экономика
net_profit = expected_resale_price - buy_price - shipping - marketplace_fee - payment_fee - repair - tax_estimate - risk_reserve

Не считать активные объявления доказательством цены продажи. Уровень уверенности должен зависеть от точности модели, состояния, комплекта и количества сопоставимых завершённых продаж.


## Правило аукционов
По умолчанию аукционы исключаются из основной ленты. Аукцион допускается в ленту только если одновременно:
- до окончания осталось от 0 до 24 часов;
- дисконт к рыночной оценке не менее 20%;
- расчётная прибыль после расходов положительная;
- рейтинг перспективности сделки не ниже 60/100.

Если время окончания неизвестно, аукцион скрывается. Пороговые значения являются стартовыми настройками MVP и могут быть изменены после проверки на реальных сделках. Истечение времени аукциона не означает, что товар продан по указанной цене.


## Разделение дат в интерфейсе
Вручную введённое объявление получает `observed_at` в момент добавления. Дата публикации вводится отдельно как `published_at`. Возраст обнаружения и возраст публикации отображаются раздельно; неизвестная дата публикации не подменяется датой добавления. Для старых записей без `observed_at` используется прежнее поле `created` как совместимый резервный вариант.


## Оценка рынка по завершённым продажам

Утилита `tools/market_estimator.py` принимает JSON с двумя массивами:

- `listings`: объявления с полями `id`, `brand`, `model`, `condition`;
- `completed_sales`: только фактически завершённые продажи с `brand`, `model`, `condition`, `status` (`sold`, `completed` или `finished`), `sold_price`, `sold_at`, `country` и `currency`.

Сопоставление строгое: нормализованные бренд + модель + состояние должны совпасть. Валюта только RUB, страна RU, срок давности по умолчанию не более 365 дней. Активные объявления, неизвестные даты, будущие даты и неподтверждённые статусы не участвуют.

Оценка рассчитывается медианой цен завершённых продаж, а не средней ценой активных объявлений. Рядом выдаются количество аналогов, разброс межквартильного диапазона, ссылки на подтверждающие продажи и консервативная уверенность. Если точных завершённых продаж нет, оценка остаётся пустой, а не подменяется догадкой.

Запуск:
```bash
python PRICE_RADAR/tools/market_estimator.py input.json -o estimates.json
```

Это отдельный проверяемый модуль. Он пока не подключён к интерфейсу и не получает автоматически историю продаж с площадок: для этого нужны законные выгрузки, API или ручной импорт.
