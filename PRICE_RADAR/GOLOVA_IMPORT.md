# Golova.Market: live public API importer

Источник проверен по публичной документации и реальному ответу API. Endpoint: `https://golovamarket.ru/api/public/listings`. Публичный read-only API не требует авторизации; документированный лимит — 60 запросов в минуту.

## Запуск

```bash
python PRICE_RADAR/tools/import_golova_market.py PRICE_RADAR/golova-cities.example.json -o golova_market_offers.json
```

Конфигурация содержит список российских городов. Для каждого города выполняется запрос к API с `city`, `per_page` и `page`. По умолчанию запрашивается до 2 страниц по 50 записей. Между запросами выдерживается минимум 1,05 секунды, то есть не более примерно 55 запросов в минуту.

## Строгие фильтры

- Включается только `type=sale`. Аренда исключается.
- Город в каждой записи должен совпасть с городом запроса.
- Валюта должна быть явно указана как RUB/RUR/₽.
- Цена должна быть числом больше нуля.
- Нужны заголовок и slug публичного объявления.
- Публичная ссылка строится по подтверждённому маршруту `https://golovamarket.ru/listings/{slug}`.
- Дата публикации в кратком ответе API отсутствует, поэтому она не выдумывается. `observed_at` фиксирует время обнаружения.
- Цены «по запросу» и записи без цены пропускаются.
- Аренда не смешивается с продажей и не попадает в расчёт перепродажи.

Города — явный белый список в конфиге. Это защищает от попадания иностранных городов (API может содержать предложения вне РФ). Список можно расширять; запросы идут только по указанным городам. Импортёр не обходит авторизацию, CAPTCHA или ограничения API.

## Важное ограничение

Golova.Market — специализированная площадка оборудования для сцены, медиа и мероприятий. Это первый живой источник, а не покрытие всех категорий товаров. Для национального поиска по всем категориям нужны дополнительные российские API/партнёрские фиды.
