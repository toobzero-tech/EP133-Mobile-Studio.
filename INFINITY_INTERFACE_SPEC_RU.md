# ∞ — Interface Specification (RU)

Версия: 1.0  
Статус: обязательный UX-контракт для Windows-приложения ∞.

## Главный принцип

Профессиональная глубина без профессиональной сложности. Основные музыкальные действия доступны на главном экране; расширенные параметры открываются по запросу. Интерфейс не должен быть копией чужого прибора: собственная компоновка, собственная визуальная система и понятные подписи.

## Визуальная система

- Основной фон: тёмный графит, поверхности на один-два тона светлее.
- Акцент: тёплый оранжевый для активного состояния и записи; зелёный для воспроизведения/готовности; красный только для ошибки или клиппинга.
- Контрастные подписи, крупные значения темпа и уровня, читаемые шрифты.
- Пэды крупные, визуально различимые и имеют подсветку выбранного/играющего/записанного состояния.
- Никаких мелких кликабельных зон, скрытых жестов как единственного способа управления или перегруженных панелей.

## Главный экран

1. Верхняя полоса: название проекта, имя паттерна, BPM, Swing, такт/позиция, Undo/Redo, Save.
2. Транспорт: Play, Stop, Record, Metronome, Loop. Кнопки имеют ясные состояния и горячие клавиши.
3. Секция пэдов: 12 больших пэдов в сетке 4×3. Клик и MIDI Note On запускают звук; velocity влияет на громкость/слой, если это поддерживает выбранный звук.
4. Секция дорожек: 8 дорожек с названием, цветовым маркером, mute, solo, arm, уровнем и индикатором сигнала.
5. Секвенсор: 64 шага, видимые номера долей, активные шаги, playhead, velocity/condition/lock-индикаторы. Масштабирование не должно скрывать текущую позицию.
6. Мини-экран состояния: waveform/спектр, выбранный звук, уровень входа и выхода, CPU/audio load.
7. Правая панель выбранного объекта: основные параметры выбранного пэда/дорожки без перехода в отдельное окно.

## Режимы рабочего пространства

- **PLAY** — пэды, транспорт, уровни и текущий паттерн.
- **STEP** — 64-шаговый секвенсор, ноты, velocity, probability/conditions.
- **SOUND** — выбор/загрузка семпла, старт/конец, tune, envelope, фильтр.
- **MIX** — 8 дорожек, посылы, панорама, мастер-шина.
- **FX** — эффекты дорожки и мастер-эффекты с крупными регуляторами.
- **SCENES** — A/B/C/D, клипы и группы, переключение сцен с квантованием.
- **RECORD** — входы, мониторинг, запись, ресемплинг и Skip Back.
- **BROWSER** — библиотека, поиск, категории, предпрослушивание, избранное и импорт файлов.

Переключение режимов не должно останавливать воспроизведение. Контекст выбранной дорожки сохраняется.

## Принципы взаимодействия

- Один клик по пэду — звук сразу; двойной клик не требуется для базового действия.
- Перетаскивание семпла из браузера на пэд или дорожку назначает звук.
- Клик по шагу включает/выключает его; модификатор или контекстная панель редактирует velocity, probability, condition и parameter lock.
- Все регуляторы показывают точное числовое значение; двойной клик возвращает значение по умолчанию.
- Undo/Redo охватывают музыкальные изменения, включая назначение семплов и автоматизацию.
- Подсказки появляются при наведении, но не блокируют работу.
- Поддерживаются мышь, клавиатура и MIDI-контроллер; основные функции не зависят только от MIDI.
- RU/EN переключается в настройках без перезапуска.

## Звуковая обратная связь и безопасность

- На каждом пэде есть визуальный отклик при срабатывании.
- Индикаторы показывают входной/выходной уровень и перегрузку.
- Clip/True Peak предупреждения не должны маскироваться обычной подсветкой.
- При смене аудиоустройства пользователь видит выбранное устройство, частоту дискретизации и размер буфера.
- Ошибки объясняют, что произошло и как исправить, без технической загадки.

## Критерии приёмки интерфейса

- Новый пользователь может запустить звук с пэда и включить шаг секвенсора без инструкции.
- Можно создать 4-тактовый паттерн, назначить звук на дорожку, сохранить проект и снова открыть его.
- Можно переключить A/B/C/D во время воспроизведения без остановки транспорта.
- Любой параметр, который меняет звук, имеет видимое значение и Undo.
- Все 8 дорожек и 64 шага доступны без открытия множества вложенных окон.
- Масштабирование окна не обрезает транспорт, пэды или текущий playhead.
- Никакая кнопка не является декоративной: если функция ещё не реализована, она явно помечена как недоступная, а не имитирует работу.

## Запрещённые UX-решения

- Главный экран, состоящий только из текста или списка кнопок.
- Пустые пэды и фиктивные индикаторы.
- Скрытые основные функции, доступные только через длинные цепочки меню.
- Сложные параметры на главном экране без необходимости.
- Кнопки, которые выглядят рабочими, но ничего не делают.
- Подмена реального аудио визуальными анимациями.
